# Solus_v2
An artistic watchface built for the Pebble Time 2 and Pebble Round 2\
Based on Solus by Graham-Bryan\
*Coded mostly by Claude.ai (Anthropic)*

## Changes in this fork
* Native display resolution on Pebble Time 2 (emery, 200×228) and Pebble Round 2 (gabbro, 260×260)
* Procedural vector starfield (replaces bitmap resource)
* Settings page for animation configuration (always on / daytime only / always off)
* Battery and memory optimisations throughout
